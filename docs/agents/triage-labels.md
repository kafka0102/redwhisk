# Triage 标签

工程技能使用五种规范化 triage 角色。本文件将其映射到本仓库 Issue tracker 的实际标签。

| 技能角色 | 仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估该 Issue |
| `needs-info` | `needs-info` | 等待报告人补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求完整，可由 Agent 自主处理 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不会处理 |

当技能提到某个角色时，使用表中对应的仓库标签。若仓库标签体系变化，更新第二列即可。
