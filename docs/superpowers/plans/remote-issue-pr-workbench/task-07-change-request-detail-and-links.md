## 目标

实现应用内 PR/MR 只读详情，包含概览、变更、检查、讨论四个内部 Tab，并完成 Issue 与 PR/MR 的双向跳转。详情加载失败时保留列表缓存，合并动作留给任务 8。

## 当前基线

- 任务 6 完成后应提供 `change_requests`、多对多 Issue 关联和详情快照契约。
- Pull requests 列表已有筛选、摘要和真实数量。
- Issue 详情已有轻量关联 PR 卡片，但数据源可能仍是旧 URL；本任务负责切换到一等实体。
- 现有 `view_change_request` 只返回标题、state 和有限检查，不足以支撑详情页。

## 本任务范围

### 详情数据

- 提供按项目、provider、number 获取 PR/MR 详情的 command。
- 首次打开时拉取列表快照之外的详情：描述、变更文件、check runs/statuses、reviews、comments。
- 详情数据写入 `change_request_details` JSON 快照。
- 页面可见且窗口聚焦时按设计默认 30 秒刷新详情；离开页面后停止。
- 详情拉取失败时保留已有快照；没有快照时展示错误和“在宿主打开”，不破坏列表状态。
- 不让前端直接拼 `gh/glab` 参数。

### 详情页面框架

- 详情直接进入内容，不显示外层 `Issues | Pull requests` Tab，不显示同步状态和刷新控件。
- 顶部展示 `PR/MR #number`、标题、state、源/目标分支、作者、提交数、变更量。
- 操作区展示“在 GitHub/GitLab 打开”，以及后续任务 8 可接入的标记就绪、请求审阅、关闭位置。
- 本任务的写操作按钮如果尚未实现，必须显示为不可用或不渲染；不得做成点击无效的假按钮。
- 内部 Tab：概览 / 变更 / 检查 / 讨论。

### 概览

- 描述 Markdown 只读。
- 关联 Issue 列表完整展示，可点击进入 Issue 详情。
- 展示审阅者、标签、评审和合并状态。
- 右侧合并框展示宿主提供的状态、全部阻塞原因、合并方式说明和“在宿主处理”入口。
- 本任务不允许执行合并；按钮必须 disabled 或跳宿主，不能伪造成功。

### 变更

- 展示文件列表、增删统计和只读 diff。
- 大 diff、二进制文件或宿主未返回内容时提供打开宿主入口。
- 不在本任务实现行内评论或编辑 diff。

### 检查

- 失败项置顶，其次运行中，再展示通过项。
- 每项展示名称、状态、耗时和日志入口。
- 总览同时展示通过/失败/运行中数量，颜色与文字并用。
- 合并阻塞原因来自宿主字段，前端不自行推断。

### 讨论

- 展示评论与 review，只读。
- 标明作者、类型、时间和 review 状态。
- 本任务不提交评论、不回复、不做 suggestion。

### Issue 与 PR/MR 双向关联

- PR/MR 详情中的关联 Issue 可进入 Issue 详情。
- Issue 详情中的关联 PR 卡片改为读取任务 6 的一等数据，展示状态、检查摘要和入口。
- 多 Issue 关联全部显示，不只取第一条。
- 任务 4 定义的 Issue 详情布局保持不变，只替换数据来源。

## 非目标

- 不执行标记就绪、请求审阅、关闭或合并。
- 不实现 PR 合并成功后的 Issue 关闭/评论。
- 不实现创建 PR 时自动关联；该链路属于任务 8。
- 不实现行内 review、评论发送、auto-merge。
- 不新增独立 PR Activity。

## 契约与测试要求

- 详情 DTO 与 TypeScript 类型同步，字段缺失允许安全降级。
- 新 command/event/错误码同步 Tauri contract。
- GitHub/GitLab fixture 覆盖四个内部 Tab 所需字段和字段缺失场景。
- 测试详情首次加载、快照缓存、刷新、失败保留列表缓存。
- 测试多个关联 Issue 完整展示并可双向跳转。
- 测试合并阻塞原因直接来自宿主投影，不由前端根据检查数自行生成。
- 测试任务 4 的 Issue 详情卡片在数据源切换后布局不回归。

## 验收标准

- 列表任意行可进入应用内详情，默认显示概览。
- 四个内部 Tab 可用，状态和内容正确。
- 检查失败项置顶，合并阻塞原因完整。
- PR/MR 详情不出现外层工作台 Tab 或同步控件。
- 关联多 Issue 完整显示，Issue 与 PR/MR 可双向跳转。
- 详情失败不丢列表缓存；无快照时仍可打开宿主。
- 指定原型场景逐项对照通过。

## 计划校准

- 宿主不返回提交数、标签、审阅者等可选字段时允许降级，不伪造占位数据。
- 大 diff 不阻塞详情闭环，记录跳宿主边界。
- 合并框在本任务只读；任务 8 复用该布局接入写操作，不重做详情结构。
- 若任务 6 的关联关系不完整，可在本任务补手动关联查询，但不得另建第二套关联模型。
