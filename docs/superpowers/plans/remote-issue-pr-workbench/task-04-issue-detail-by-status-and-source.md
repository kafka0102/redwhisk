## 本任务范围

### 详情数据

- 增加 Issue 详情的远程投影读取，返回宿主、仓库、远端编号/URL、open/closed/unavailable、作者、指派、标签和同步状态。
- 增加远程评论与系统事件存储，遵循设计文档 6.2 的分表语义。
- 主题、正文、本地评论/动作、远程评论/事件和 Agent 交付按时间合并；前端只消费统一时间轴，不直接查 SQLite。
- 本地评论不得混入远程评论的唯一键或写回语义。
- 评论/事件同步失败时保留已有时间轴；详情基础信息仍可显示。

### 顶部动作

| 状态 | 本地 | 远程 |
| --- | --- | --- |
| 待办 | 返回、运行、保存、删除 | 返回、状态下拉、运行、更多 |
| 进行中 | 返回、状态下拉、更多 | 返回、状态下拉、更多 |
| 待审核 | 返回、状态下拉、完成、更多 | 返回、状态下拉、完成、更多 |
| 已完成 | 返回、状态下拉、查看回看、更多 | 返回、状态下拉、查看回看、更多 |

- 远程待办不得进入本地编辑表单；`dialogMode === "create" || status === "backlog"` 的判断必须追加 `source === "local"`。
- 已完成不能直接进入待审核；不能续接时不能进入进行中。
- 向前切换直接生效；回退、执行中标记完成、退回待办并处理 worktree 时沿用现有确认语义。
- 更多菜单包含编辑和删除；远程 Issue 的编辑只改本地副本，不写回远端。
- 远程 Issue 的删除只删除本地副本，不删除远端对象。

### 主体与侧栏

- Issue 详情不显示外层 `Issues | Pull requests` Tab、同步状态或刷新控件。
- 标题使用正确的本地或远程编号；标题下不再放重复状态标签。
- 待办没有 Session 时不显示会话和运行参数，不渲染“尚未运行”空卡片。
- 右侧只渲染真实存在的卡片：宿主、关联 PR、会话信息、运行参数。
- 远程宿主卡片的标题行为 GitHub 或 GitLab；“打开 GitHub/GitLab”放在该卡片标题行。
- 会话信息卡片的“查看会话”放在卡片右侧，不显示额外会话状态标签。
- 标签在主区正文上方；只读标签不伪造本地可编辑标签。

### 编辑体验

本地待办和远程 Issue 的“编辑本地副本”必须沿用现有编辑体验：

- 标题是顶部单行输入框。
- 正文复用现有富文本编辑器。
- 工具栏包含正文级别、加粗、引用、代码块、列表、图片、附件和清除格式。
- 附件入口在工具栏，不在编辑页额外增加“添加附件”大按钮。
- 标签选择器在编辑器下方，已选标签显示彩色 chip。
- 附件卡片显示类型、文件名、View、Down、Del。

### 关联 PR 过渡契约

任务 4 依赖任务 3，尚未完成任务 6 的一等 PR 模型。为避免重复返工：

- 本任务可以定义 `LinkedChangeRequestSummary` 展示契约，但数据源先适配现有 `issue_pull_requests` URL。
- 能查询到状态时显示检查/评审摘要；查询失败时至少保留可打开的主机链接。
- 任务 7 负责把数据源替换为 `change_requests` 和详情快照，不修改 Issue 详情的卡片位置或整体布局。
- 若当前 Issue 没有关联 PR，不渲染空 PR 卡片。

## 非目标

- 不在本任务实现远程 Issue 新建、关闭、摘要评论或远端不可用后的保留/解绑/重试行为。
- 不在本任务实现 PR 列表、PR 详情四 Tab 或 PR 合并。
- 不实现远程正文/标题/标签/指派的写回。
- 不重做现有富文本编辑器和附件上传协议。

## 契约与测试要求

- 新增详情 DTO 时同步 Rust/TypeScript 类型、Tauri contract 和 DTO parity。
- 时间轴 DTO 必须能区分来源和 actor，不让远程评论显示成本地评论。
- 状态操作仍走现有 `CommandError` 和 i18n，不在前端自行伪造完成流程。
- 测试覆盖本地/远程 × 四状态矩阵。
- 测试覆盖远程时间轴排序、重复评论幂等、详情失败保留基础信息和无 Session 不渲染侧栏。
- 测试覆盖顶部动作矩阵、远程待办不进入编辑页、本地待办直接编辑。
- 测试覆盖远程删除不会调用宿主删除。

## 验收标准

- 八个状态/来源组合的布局与动作符合上表。
- 远程待办点击卡片进入只读详情；本地待办点击卡片进入编辑表单。
- 远程评论、系统事件、本地动作和 Agent 交付按时间正确展示。
- 无 Session 的待办不显示空会话卡片；运行中/待审核/已完成有 Session 时显示现有信息。
- 打开 GitHub/GitLab 位于宿主卡片标题行。
- 查看会话位于会话卡片右侧。
- 本地与远程已完成状态都走正确的回看/重新打开路径。
- 指定原型场景逐项对照通过。
