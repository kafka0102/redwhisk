# Settings 页面布局规范

## 适用范围

本文约束 Project Settings 页面后续所有模块的外层布局。Settings 当前包含 `General` 和 `Agents` 两个模块，后续新增模块必须复用同一套布局模板，不为单个模块重新设计页面骨架。

## 布局结构

Settings 页面使用左右两栏：

- 左侧为菜单栏，承载设置模块入口。
- 中间为可拖动分割线。
- 右侧为当前设置模块内容。

左侧菜单栏默认宽度、最小宽度、最大宽度必须与 Agents Activity 的左侧 Session list 保持一致。分割线必须从页面顶部连续延伸到底部，拖动调整宽度的实现参考 Agents Activity 的 splitter 行为，包括 `col-resize` 光标、拖动期间禁止文本选择、focus 样式和可访问标签。

## 菜单项

Settings 菜单项由图标和文字组成。当前菜单项包括：

- `General`
- `Agents`

图标优先使用项目已依赖的 `lucide-react`。如后续改用外部图标资源，必须保存为本地资产，并确认 license 允许随应用分发。

选中项必须使用灰色或等价的 `var(--color-surface-muted)` 背景色进行区分，并保留语义状态，例如 `aria-pressed`。选中态不能只依赖颜色表达。

## 右侧内容模板

点击任一菜单项时，右侧区域必须使用统一模板：

1. 顶部显示当前选中的菜单名称，例如 `General` 或 `Agents`。
2. 标题前展示与左侧菜单一致的小图标。
3. 标题下方渲染该菜单对应的具体内容。

右侧具体内容容器在可用宽度大于 900px 时居中显示，最大宽度固定为 `900px`；当可用宽度小于 900px 时，容器宽度为 `100%`。

标题、表单、列表、状态信息和空态不得与左侧菜单、分割线或页面边界重叠。模块内部可以组织自己的表单和列表，但不得改变 Settings 页面的外层两栏和内容宽度约束。

## 非目标

本规范不新增 Settings 业务字段，不改变 Project Settings 与 Global Settings 的产品边界，不调整 Agent Profile 的数据模型和状态流。
