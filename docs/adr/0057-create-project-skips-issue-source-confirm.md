# 0057. 创建项目弹窗不确认来源模式

## 状态

采纳（待执行）。

## 背景

设置页更换 Issue 来源模式前必须确认，取消则模式不变。创建项目要改成两步：第一步只填名称、仓库路径和工作树，第二步照抄项目设置的 Issues 页，提交时才写入。恢复已从列表移除的项目时，第二步先填回已保存的来源模式、同步和完成后动作，提交再按表单覆盖。若这里也弹出确认，创建流程会被设置页的即时保存确认打断。

## 决定

1. 创建项目弹窗里改来源模式不单独确认，提交时直接写入。全新项目和恢复已移除项目都一样。
2. 设置页仍须先确认。取消则模式不变，确认后才改变可见性。
3. 来源模式仍不删除、不改写已有 Issue、评论、附件、Session 或完成记录。

## 后果

- 恢复项目时，用户可以在第二步改掉来源模式并直接提交，看板可见性会随提交变化，中间没有确认框。
- 设置页的确认对话框保持不变。

## 考虑过的替代方案

| 方案 | 未采纳原因 |
| --- | --- |
| 只有恢复已移除项目时才确认 | 创建弹窗仍会被确认框打断 |
| 第二步任何模式切换都确认，包括全新项目 | 全新项目还没有 Issue，确认没有可见性后果 |
