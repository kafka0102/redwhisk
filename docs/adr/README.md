# 架构决策记录（ADR）

ADR 只记录仍有效、会影响后续实现取舍的决策；功能计划和调研继续放在 `docs/superpowers/` 与 `docs/survey/`。新 ADR 使用递增编号，包含背景、决定、后果、代码事实来源和替代方案。

当前有效基线见 [0001 核心架构边界](./0001-core-architecture-boundaries.md)、[0002 Issue 时间轴事件模型](./0002-issue-timeline-event-model.md)、[0003 Agent Turn 完成自动发表 Issue 评论](./0003-agent-turn-comment-auto-post.md)、[0004 应用版本检测走 GitHub Release 外链引导](./0004-app-update-check-via-github-release.md)、[0005 工作区变更视图渲染件抽取为共享模块](./0005-extract-shared-workspace-changes-view.md) 与 [0006 Session 输入草稿使用纯内存缓存并按 Session 删除清理](./0006-composer-draft-in-memory-cache.md)、[0007 Agent Turn 异常终止的可观测性与会话内提示](./0007-agent-turn-abnormal-termination-observability.md)、[0008 变更视图提升为顶层 Activity 并按运行态条件轮询](./0008-changes-promoted-to-activity-with-conditional-polling.md)、[0009 变更专属件拆分到独立 features/changes](./0009-changes-split-into-own-feature-dir.md)、[0010 Worktree 生命周期深 module 与统一 git 执行 adapter](./0010-worktree-lifecycle-deep-module.md)、[0011 Agent Session 构造侧 Provider Factory](./0011-agent-session-provider-factory.md)、[0012 完成流程 Effect 解释器收为深 module](./0012-completion-effect-interpreter-deep-module.md)。当决策被替换时，新建 superseding ADR，不回写历史记录。
