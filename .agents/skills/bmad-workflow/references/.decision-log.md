# bmad-workflow 决策日志

## 2026-06-10

- 创建 `bmad-workflow` 作为 workflow skill，而不是 persona agent。原因：用户目标是自动串联 BMad 规划、story、开发和评审流程，不需要新的长期身份或记忆。
- 以 `.agents/skills/bmad-dev-workflow` 为基础，但扩展前置规划能力：当自然语言输入没有可用 epic/story 时，先生成最小 epic/story seed，再委托 `bmad-create-story`。
- 不复制 `bmad-create-story`、`bmad-dev-story`、`bmad-code-review` 的内部流程。新 skill 只负责编排、规划种子、handoff、review follow-up loop 和最终提交约束，避免与上游子流程漂移。
- 默认 `require_story_approval = false`、`review_policy = "automatic"`、`auto_continue_review_fix_loop = true`，匹配“根据输入自动创建 story，然后 dev 和 code review”的目标。
- 若现有 epic 标记为 `done`，默认不静默重开；创建新 epic 更符合状态可靠性，除非用户明确要求扩展已完成 epic。
