# 01: 持久化智能体显示顺序并按它返回列表

**What to build:** 已配置的智能体按全应用一份显示顺序返回。升级前已存在、还没有顺序的智能体，第一次按「启用在前、同组按 id 升序」排好并记住。手动新建、自动播种，以及软删后再次保存出现的智能体，都接在整张表最后。修改内容或切换启用状态不改变它所在的位置。

**Blocked by:** None（可以立即开始）

**Status:** done

- [x] 列出未删除的 Agent profile 时，项目级与全局级按同一份显示顺序排列，而不是按 id
- [x] 没有顺序值的存量 profile 被排成启用在前、同组 id 升序，并在随后的列表中保持该顺序
- [x] 手动新建的 profile 出现在当前最后一位，包括当末位已是禁用 profile 时
- [x] 同一轮自动播种的 profile 按既有播种顺序依次出现在表尾
- [x] 编辑 profile 或切换启用状态后，它的相对位置不变
- [x] 软删后再次保存为未删除的 profile 出现在表尾

## Comments

粒度假设：本票把顺序列、回填、追加和「更新不挪位」收在设置服务这一条缝上。拖拽写入与前端留到后续票，避免单票同时改迁移、命令契约和界面。

实现：`0054_agent_profiles_display_order` 给 `agent_profiles` 增加可空 `display_order`。列表与保存都先把未删除且尚无顺序的行按「启用在前、同组 id 升序」写入，再按 `display_order, id` 返回。手动新建、自动播种、软删后重新保存追加到当前未删除最大顺序之后；编辑字段或切换 enabled 不改顺序。未新增 reorder command，也未改前端排序。验收在 `service_display_order_tests`。
