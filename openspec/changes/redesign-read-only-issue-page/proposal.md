# 改版只读 Issue 详情页

## 背景

只读 Issue 详情页当前右侧动作区包含返回、状态切换和删除按钮，删除作为高风险操作过于直接；详情主体仍使用左右栏布局，与编辑页体验不一致。描述中的附件渲染也不完整，图片 token 只显示名称，非图片附件缺少可预览和下载入口。

## 变更范围

- Header 保留返回和状态切换按钮，将删除按钮替换为横向三点“更多”菜单。
- “更多”菜单提供编辑 Issue、查看会话、查看总结和删除 Issue，沿用现有跳转、总结弹窗与删除确认行为。
- 将只读详情主体改为类似编辑 Issue 页的单栏布局，保持现有视觉风格。
- 修复描述 Markdown 中附件 token 的渲染：图片使用可显示的绝对路径渲染，非图片附件展示为附件项并支持下载与可用类型预览。
- 有标签时在描述下方显示分割线，并按现有标签样式平铺展示。

## 非目标

- 不调整 Issue 状态机、后端数据结构或附件持久化模型。
- 不重做 Issue 编辑页或列表页。
- 不新增未被现有附件能力支持的文件预览格式。
