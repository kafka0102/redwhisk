# Session Tab 工具入口改版

## 背景

Agents Activity 当前在 Session 顶部使用独立终端图标打开内联终端区域，终端出现在 Session 页面下方。新的交互要求把终端能力移入与 Session 内容同级的 Tab 体系：Session Tab 保持首个内容入口，后面通过 `+` 菜单添加终端或浏览器工具 Tab。

## 目标

- 移除 Session 顶部独立终端图标入口。
- 在 Session 主窗口 Tab 栏中保留 Session 内容 Tab，并在其后提供 `+` 菜单入口。
- `+` 菜单包含“终端”和“浏览器”两个选项，并使用默认图标。
- 选择“终端”后在当前 Session Tab 容器内新增可关闭终端标签页。
- 支持多个终端标签页，最多 10 个；超过上限时提示不支持继续添加。
- 选择“浏览器”后新增浏览器标签页，显示地址输入框和嵌入式浏览区域。
- 浏览器地址栏支持输入地址后按 Enter 访问；再次按 Enter 可刷新或重新加载当前地址。

## 非目标

- 不改变 Codex 结构化消息流和 composer 的消息发送语义。
- 不改造后端临时终端启动能力；继续复用现有 Session 终端工作目录解析。
- 不实现终端或浏览器 Tab 的持久化恢复。
- 不实现浏览器历史、书签、多进程调试或跨域控制等完整浏览器功能。
- 不改动 Project Terminals 的持久终端配置和独立使用路径。

## 影响范围

- `src/features/agents/agents-activity.tsx`：移除旧终端入口，接入新的 Session 工具 Tab 容器。
- `src/features/agents/`：拆分新增工具 Tab、终端 Tab、浏览器 Tab 等受控组件，避免继续扩大 Activity 文件复杂度。
- `src/shared/i18n/**` 或 feature 内消息 helper：新增菜单项、Tab 标题、上限提示、地址栏等文案。
- `src/app/app.css` 或相关样式文件：调整 Session 主窗口和工具 Tab 布局。
- 测试：覆盖新增菜单、终端多开/关闭/上限提示、浏览器地址输入行为。

## 验收标准

- Session 顶部不再显示独立终端图标。
- Session 主窗口首个 Tab 仍为 Session 内容；其后显示 `+` 工具菜单入口。
- 点击 `+` 后菜单展示“终端”和“浏览器”，两项均带图标。
- 选择“终端”会新增一个终端 Tab，终端渲染在 Tab 内容区内，不再出现在页面最下方。
- 终端 Tab 可关闭；可连续新增多个终端；第 11 个终端新增请求会显示不支持提示且不新增 Tab。
- 选择“浏览器”会新增浏览器 Tab，下方显示地址输入框和嵌入式浏览区域。
- 在浏览器地址栏输入地址并按 Enter 后，浏览区域访问该地址；对已有地址再次按 Enter 可重新加载。
