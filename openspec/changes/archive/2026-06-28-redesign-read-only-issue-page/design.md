# 设计说明

## 实现策略

- 复用现有 shadcn 菜单、对话框和按钮组件实现 Header 更多菜单，避免新增基础控件。
- 详情页保留当前数据加载和命令调用入口，只调整页面编排和动作入口位置。
- 描述渲染优先复用现有富文本/Markdown 附件解析能力；若当前只生成名称文本，则在只读渲染阶段把本地附件路径归一化为可供 `<img>` 访问的绝对 URL。
- 非图片附件在描述流中以附件块展示，动作复用现有预览和下载方法，无法预览的类型只展示下载。

## 风险与取舍

- 附件 token 可能来自历史 Markdown，不保证都能在附件列表中找到对应文件；此类缺失附件应保留可读名称并避免渲染破损图片。
- 单栏改版只影响只读详情页，不抽象到其它页面，避免扩大变更面。
