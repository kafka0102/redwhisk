# 将 Issue 描述改为富文本编辑

## 背景

Issue 创建和编辑页当前使用 Markdown 文本编辑器，并在编辑器下方提供附件上传图标。用户希望描述字段升级为富文本编辑体验，常用格式和文件插入都在编辑器内完成，同时保留可复用组件边界。

## 变更范围

- 将 Issue 创建和编辑时的描述字段替换为基于 Quill 的富文本编辑器。
- 封装通用富文本编辑器组件，支持标题、加粗、有序列表、无序列表、图片、附件插入和常用 Markdown 快捷输入。
- 将图片作为编辑器内容直接显示，将非图片附件作为图标卡片显示在编辑器内部。
- 移除 Issue 编辑器下方的附件上传图标，标签选择仍保留在编辑器下方工具区。
- 保持 Issue 描述持久化为 Markdown 文本，避免改变后端数据模型与运行提示构建逻辑。

## 非目标

- 不新增后端附件存储模型。
- 不迁移历史 Issue 描述格式。
- 不引入跨页面富文本业务功能；通用组件只暴露当前必要能力。
